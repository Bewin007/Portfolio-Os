# BEWIN.OS // Futuristic Developer Portfolio & Development Journey

A cinematic, interactive developer portfolio built with **React, Vite, TypeScript, Tailwind CSS, Framer Motion, and Lucide React**.

The website is structured around an **interactive DEVELOPMENT JOURNEY**, communicating how the developer evolved from early programming discovery through university experimentation, systems engineering, professional software development, and modern compound AI architectures.

---

## ⚡ Key Highlights & Features

1. **Cinematic Hero**:
   - `BEWIN.OS [v1.0.0] // SYSTEM ONLINE`
   - Editorial typography, live system telemetry HUD, interactive mouse-repelling particle canvas.
   - Smooth entrance animations and one-click *"EXPLORE JOURNEY"* trigger.

2. **Development Journey (Core Centerpiece)**:
   - Scroll-driven timeline across 6 distinct eras:
     - `YEAR 01` — Discovery & First Spark
     - `YEAR 02` — Experimentation & Full-Stack Horizons
     - `YEAR 03` — Building & Architectural Groundwork
     - `YEAR 04` — Engineering & High-Performance Systems
     - `PROFESSIONAL` — Software Engineering at Scale
     - `NOW` — AI, Autonomous Systems & Continuous Learning
   - Sticky chapter navigator ribbon, glowing progress tracker, distinct layout compositions, and clearly structured sample milestones.

3. **Cumulative Technology Evolution**:
   - Interactive timeline scrubber and **"PLAY TIMELAPSE"** controller showing how tools compound over time (from 7 in Year 01 to 39 at Present).

4. **Engineering DNA Constellation**:
   - Animated SVG mesh graph connecting Systems, Backend, Databases, Frontend, DevOps, and AI.
   - Dynamic energy packet pulses and detailed inspection drawer (no fake percentages).

5. **Project Archive & Case Studies**:
   - Technical dossiers (`CASE // 001 HYPERION-CORE`, `SYNAPSE-RAG`, `OMNI-MESH`, `NEXUS-GATEWAY`, `SPECTRA-TRACE`, `AURA-MEM`).
   - Deep-dive case study modal with animated architecture flow diagrams and decision trade-off logs.

6. **First-Principles Experiment Lab**:
   - Playable simulators: Token Bucket Rate Limiter, Vector Embedding Distance Calculator, and Heap Memory Allocator.

7. **Engineering Problem-Solving Methodology**:
   - `PROBLEM` → `EXPERIMENT` → `ITERATION` → `SOLUTION` → `LESSON`.

8. **Current State (`NOW`)**:
   - Live moving ticker and transparent 3-tier competency matrix (*Experienced With*, *Building With*, *Exploring*).

9. **Recruiter Mode vs. Story Mode**:
   - One-click toggle in the header for a condensed executive briefing with resume download and direct email copy.

10. **Interactive CLI Terminal (`>_ CLI`)**:
    - Functional terminal popup (`whoami`, `ls`, `cat journey`, `projects`, `status`, `sudo hire`, etc.).

11. **Quick Tour (`⚡ TOUR`)**:
    - Auto-scrolling interactive walkthrough with step-by-step guidance.
